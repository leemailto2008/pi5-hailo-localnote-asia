# 🐞 Issue 回報（給測試同事與工程端）

2026-11-20 起（版本 3ea6c8e），網頁頂端有「🐞 Issue 回報」按鈕。測試時遇到問題，按一下就把當下狀況存在盒子上，事後工程端拿出來重現、除錯。

## 同事怎麼用
1. 發現問題時按網頁頂端「🐞 Issue 回報」（錄音中也可以按，不會影響錄音）。
2. 寫下看到什麼、當時在做什麼、預期應該怎樣（必填）；名字選填。
3. 需要時勾選：
   - 「附上本場逐字稿」：即時稿、即時翻譯、高精度稿、紀要。
   - 「附上本場錄音最後 N 分鐘」：1／3／5／10 分鐘，錄音結束後才有。
   - 這兩項可能含會議內容，預設不勾。
4. 按「送出回報」，畫面會顯示回報編號。

不用網路也能用，熱點模式下一樣可以存。

## 自動記下的東西
- 時間、主機名稱、版本（commit）。
- 目前設定：語音語系、即時稿引擎、即時翻譯、麥克風、會議詞彙數。
- 會議或錄音狀態（job id、進度、各項指標）、高精度稿狀態、/health、藍牙狀態（只用暫存，不打擾錄音）。
- 服務 log：按下前 15 分鐘，最多 3,000 行。
- 瀏覽器：網址、瀏覽器版本、螢幕大小、最近 50 筆網頁錯誤與提示訊息。

## 存在哪裡、保留多久
- 盒子上的 `/home/pi/telegram_agent/data/feedback/<時間>_<主機>_<4 碼>/`，裡面有：
  - `feedback.json`
  - `service.log`
  - `transcript.txt`（有勾才有）
  - `audio.ogg`（有勾才有）
- 部署更新與重開機都不會刪掉；保留 90 天、最多 200 筆、總量 300 MB，超過刪最舊的。

## 工程端怎麼取出
- 網頁：在「🐞 Issue 回報」視窗下方的「已存的回報」裡，可以下載單筆 zip，或「全部打包下載」。
- API：
  - `GET /api/feedback`：清單
  - `GET /api/feedback/<id>`：單筆內容
  - `GET /api/feedback/<id>/zip`：單筆 zip
  - `GET /api/feedback/export.zip`：全部打包
- PC 腳本：`powershell -File tools\pull_feedback.ps1 -Box 192.168.50.229`，會解壓到 `.cc_scratch\feedback\`。
- localnote agent 每輪喚醒會自動檢查 .229／.228 的新回報並拉回分析。盒子在熱點模式時連不到，等它回到家用 Wi-Fi 才會拉回。
